## 数据集摘要
该数据集由DJI MAVIC 2无人机在80m高度垂直正射采集，包含200张街道航拍影像，标注格式为VOC XML，类别为地面垃圾。场景为城市街道区域，背景包含路面、行道树、道路附属设施，标注规范，可直接用于YOLO系列目标检测模型训练。![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/c1e2b2e3b48c41b18aeb7b5981132a44.png)


## 应用场景
城市道路环保巡检、街道垃圾自动识别、环卫监测、低空遥感目标检测、市容环境督查。![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/bb62f2c14bd6494f903f8492c1a507df.png)


## 应用价值
1. 依靠无人机航拍自动识别街道散落垃圾，替代人工沿路巡查，提升环卫巡检效率；
2. 支撑市容环境动态监测、垃圾点位统计，为环卫调度、环境考核提供数据支撑；
3. 适合环保方向科研、毕业设计、轻量化落地模型训练。![在这里插入图片描述](https://i-blog.csdnimg.cn/direct/734f61dbf3874182ae337586790eb2ba.png)
